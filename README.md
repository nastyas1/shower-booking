**Shower Booking System** — это автоматизация бронирования душевых кабинок в общежитиях, фитнес-центрах и гостиничных комплексах. Проект представляет собой **модульный монолит**, разделенный на независимые логические слои. 

## Ключевые возможности

### Для Пользователя (Мобильное приложение)
- **Авторизация и безопасность:** Регистрация и вход по JWT-токенам.
- **Просмотр расписания:** Интерактивный календарь со свободными слотами.
- **Бронирование:** Выбор кабинки и времени с защитой от двойного бронирования.
- **Личный кабинет:** Просмотр своих броней, возможность отмены.
- **Обратная связь:** Отправка заявки о неисправности.

### Для Администратора (Веб-интерфейс Django Admin)
- **Управление кабинками:** Добавление, редактирование и блокировка кабинок в системе.
- **Управление пользователями:** Блокировка нарушителей.
- **Обработка заявок.** 

## Технологический стек

### Backend
- **Язык:** Python 3.11+
- **Фреймворк:** Django + Django REST Framework (DRF)
- **База данных:** PostgreSQL 16 (локальный запуск)
- **Аутентификация:** JWT
- **Документация API:** Swagger

### Mobile
- **Фреймворк:** Flutter (Dart)
- **Платформа:** Android (сборка APK)

### Инструменты разработки
- **Контроль версий:** Git + GitHub
- **Управление задачами:** GitHub Projects (SubIssues, Issues, Milestones)

## Архитектура проекта

**Бэкенд разделен на независимые приложения (apps):**
- **`users`**: Аутентификация (JWT), профили, разграничение прав (Пользователь/Администратор).
- **`cabins`**: Управление кабинками.
- **`bookings`**: Ядро системы. Логика расчета свободных слотов.
- **`maintenance`**: Обработка заявок на ремонт.

**Мобильное приложение (Flutter) разделено на слои:**
- **`presentation`**: Экраны и виджеты.
- **`data`**: Работа с API и сохранение токенов.
- **`models`**: Модели данных.
